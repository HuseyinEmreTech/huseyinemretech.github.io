## ✨ Modern Tasarım & UX

Bu portfolyo, geleneksel tasarımların ötesine geçerek **Modern Professional Tech** estetiğiyle geliştirilmiştir:

- 🌌 **Aurora Background** - Hareketli ve derinlik algısı yaratan dinamik arka plan.
